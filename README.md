# Omni Core

> AI-Powered Multi-Tenant Business Operations Platform

Omni Core is a modern enterprise management platform designed to help organizations manage people, projects, operations, and business growth from a single workspace.

Unlike traditional management software, Omni Core is being built around an intelligent executive assistant that helps leadership make better operational decisions using company data.

---

## Vision

Most companies use multiple disconnected tools to manage employees, projects, communication, and operations.

Omni Core brings everything together into one secure platform while providing AI-assisted insights that reduce manual work and improve decision making.


```bash

```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
